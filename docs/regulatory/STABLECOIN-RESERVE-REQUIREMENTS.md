# Stablecoin Reserve Requirements

## Reserve evidence stack
- Reserve registry
- Monthly reserve report
- Reserve evidence hash
- Attestation record
- Public proof endpoint

## Governance requirements
- CEO/CFO certification workflow
- Board approval workflow
- Versioned report retention
- Change-control for reserve methodology

## Risk controls
- Custodian concentration limits
- Reserve diversification checks
- Interest-rate and maturity monitoring
- Stress scenario reporting
